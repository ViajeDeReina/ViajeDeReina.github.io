# 화면 프로토타입

중장년 대상 문제풀이 화면을 빠르게 검증하기 위한 정적 프로토타입입니다. 빌드 도구 없이 HTML/CSS/JS 세 파일로 동작하며, `data/realtor/2024-35-1-1.json`(이 폴더 기준)을 읽습니다.

## 실행

프로젝트 루트(`test/`)에서:

```bash
python -m http.server 8080
```

브라우저에서 `http://localhost:8080/silverStudies/` 접속. 휴대폰으로 보려면 같은 와이파이에서 `http://<PC IP>:8080/silverStudies/`.

## 들어 있는 화면

| 화면 | 내용 |
|---|---|
| 홈 | 시험 선택 카드 (공인중개사 1차, 나머지는 "준비 중") |
| 시험 메인 | 진도율·정답률, 이어서 풀기, 과목별 연습, 모의고사, 틀린 문제, 별표, 설정, 출처 표시 |
| 문제 (연습) | 한 화면 한 문제, 보기 선택 → 정답 확인 → 맞음/틀림을 색 + 글자로 표시 → 해설 |
| 문제 (모의고사) | 80문제·100분 타이머, 정답은 제출 후 공개 |
| 결과 | 과목별 점수, 합격 기준(과목 40점·평균 60점) 판정, 번호별 다시 보기 |
| 설정 | 글자 크기 3단계, 기록 지우기 |

학습 기록은 브라우저 저장소(localStorage, 키 `easyexam:v1`)에만 저장됩니다.

## 프로토타입 한계
- 시험 데이터가 한 회차(80문항)로 고정되어 있습니다.
- 오프라인(PWA), 문제 읽어주기(TTS), 로그인은 아직 없습니다.
- 본 개발 시 Astro 등으로 옮기면서 화면 구성과 스타일 규칙은 그대로 가져갈 수 있도록 CSS 변수로 정리해 두었습니다.
